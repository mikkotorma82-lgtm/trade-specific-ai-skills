# Trade-specific AI skills

By Törmän Liikenne Oy.

Two paid skills are available through Agensi. This repository is an introduction with fictional input examples; it does not contain the paid skills.

## Construction Tender Review

For contractors reviewing tender documents before pricing. It turns supplied text into a scope matrix, a risk list and ranked clarification questions, with references to the source clauses.

It does not price a job, take quantities from drawings or provide legal advice.

Fictional input example: "Review this excerpt for an HVAC subcontractor: clause 3 includes ventilation commissioning; appendix B is referenced but has not been supplied. Identify missing documents and draft clarification questions." This illustrates an input, not a tested result.

View the skill: https://www.agensi.io/skills/construction-tender-review

## Shopify Listing Audit

For merchants checking existing product text or product CSV rows. It returns ranked findings, replacement text based on supplied facts and a bulk-fix table. It checks only the information you provide and does not connect to or change your store.

Fictional input example: "Audit this product text: Cotton tote bag. Material: 100% cotton. Size: not provided. Description: The best bag in the world." This illustrates an input, not a tested result.

No sales or search-ranking results are promised.

View the skill: https://www.agensi.io/skills/shopify-listing-audit-ranked-fixes-and-rewrites
